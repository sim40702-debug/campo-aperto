Server non raggiungibile

Non riesco a collegarmi ai server di Campo Aperto. Puoi giocare offline: partita rapida, allenamento, competizioni, carriera e le tue squadre funzionano anche senza internet. Account, monete, scommesse, shop e partite online tornano quando i server rispondono.
