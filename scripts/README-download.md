# Campo Aperto — download

Gioco di calcio 3D originale, undici contro undici: contro l'IA, con gli amici in rete locale oppure online,
in competizioni, in una carriera da allenatore e in allenamento.

## Scarica

Apri l'ultima versione in **[Releases](../../releases/latest)** e scegli il file per il tuo computer:

| Sistema | File |
|---|---|
| Windows (installer) | `CampoAperto-<versione>-win-x64.exe` |
| Windows (senza installazione) | `CampoAperto-<versione>-portable.exe` |
| Mac Apple Silicon (M1, M2…) | `CampoAperto-<versione>-mac-arm64.dmg` |
| Mac Intel | `CampoAperto-<versione>-mac-x64.dmg` |
| Linux (tutte le distribuzioni) | `CampoAperto-<versione>-linux-x86_64.AppImage` |
| Linux (Ubuntu, Debian, Mint) | `CampoAperto-<versione>-linux-amd64.deb` |

- **Windows:** se compare "Windows ha protetto il PC", scegli *Ulteriori informazioni → Esegui comunque*.
- **Mac:** trascina Campo Aperto in **Applicazioni**; al primo avvio clic destro sull'app → *Apri*.
- **Linux:** `chmod +x CampoAperto-*.AppImage` e poi aprilo, oppure `sudo apt install ./CampoAperto-*.deb`.

## Aggiornamenti

Una volta installato, il gioco controlla da solo le versioni nuove e si aggiorna dall'app
(**Nuovo aggiornamento disponibile → Aggiorna ora**). I file `latest*.yml` di ogni versione servono a questo.
